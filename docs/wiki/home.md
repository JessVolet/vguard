# VGUARD Wiki Home

Welcome to the VGUARD documentation wiki. 

VGUARD is a declarative Volume Guard and Storage Infrastructure Policy Engine. It allows system administrators to define their storage permissions in a central `vguard.conf` (JSON) and safely enforce or audit these rules across their infrastructure without breaking containerized workloads (Docker/Podman).

## Quick Links
- **Installation:** Check out the main README for installation instructions.
- **Commands Overview:** Run `vguard --help` or `vguard selected --help` for a quick reference in your terminal.
- **Configuration:** Learn how to use `vguard.conf` to declare your Single Source of Truth (SSOT).
